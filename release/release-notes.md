- **Collapsed output is compact.** A folded block — tool result, thinking block, or compaction handoff — renders as exactly one row: its header, with the `▸ N lines` badge as the only count and the head of the content riding the same line. The frame rows, the interior preview row with its second hidden-count marker, and the blank rows between consecutive folded results are gone; a screen of collapsed tool output is now a stack of single rows instead of rules and gaps. Expanded rendering is unchanged, and thinking folds keep their content behind the toggle by design.
- Changed: the fold decisions — the short-content threshold, the fold default, the separator rule, the preview rule — come from the shared platform policy in `@pellux/goodvibes-terminal-shell`, the same module the terminal app reads, so the two renderers cannot drift apart again.
- Fixed: connected-host calls dial the daemon where it answers. Every client-side URL built from the configured host maps a wildcard bind (`0.0.0.0`, `::`) to loopback before dialing, and the transport no longer refuses wildcard hosts as "public" — so profile reads and writes work over a daemon deliberately bound for LAN access. Pairing and QR URLs are deliberately excluded: another device reads those, and the right answer there is this machine's LAN address.
- Fixed: `/collapse thinking` folds the reasoning block; its collapse state was registered but nothing read it.
- Changed: the bundled GoodVibes platform runtime is 2.0.3, and the daemon this Agent installs alongside itself is 1.28.5.
