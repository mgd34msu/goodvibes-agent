- **Fixed: recording a fact about yourself lands in the right field.** The profile tool declared its field id as free text with two examples, so a model asked to save a name, an address and a spouse invented ids that do not exist — `full_name`, `home_address`, `wife` — had every one of them refused, and fell back to writing the facts as prose notes. The tool now declares the platform's own field registry as the allowed values, grouped by section with the label each one writes, generated from the registry so the two cannot drift apart.
- Changed: the profile tool states which things are prose by design — people, places, work, standing notes and dates — so a relationship or a birthday is no longer attempted as a field, refused, and then written a second way.
- **Fixed: asking what this platform can do no longer answers "nothing" when the answer is "quite a lot".** A question about payment cards and spending limits searched the settings catalog, got zero results and a count reporting that zero settings exist, while the platform held 32 payment settings and a guided card flow. Three faults combined: the reported total was the size of the match rather than the size of the catalog, the one field that could have said "your query emptied this page, not the platform" was skipped exactly when the page was empty, and matching required the entire query to appear as one contiguous run of text — so every phrase longer than a word failed, though its individual words matched dozens of keys.
- Changed: catalog searches understand plain words. A key is searched as words rather than as a dotted identifier, alongside its description and a small vocabulary of the terms people actually use for a domain; a phrase that matches nothing strictly falls back to its individual words, labelled as a looser match and offered as candidates rather than auto-resolved.
- Changed: an empty search page names the catalog it searched and points at the others, and a page holding payment settings names the guided card flow, which no setting can carry out.
- Changed: the bundled platform runtime is 2.0.4 and the daemon this Agent installs alongside itself is 1.28.6 — a corrupt watcher snapshot is quarantined with a receipt instead of crash-looping the daemon, and an unknown profile field id is refused with the valid ids named.
