The Agent now paints only while it owns the screen.

Nothing is painted outside the Agent's own screen anymore, so quitting returns exactly the shell you left.
- **Fixed: an unnamed transcription or synthesis request goes to the voice provider the user configured** (platform runtime 2.0.11). The provider picker used to answer "use whatever is configured" with the first name on its internal list — a cloud provider — even when that provider had no key and the machine carried fully provisioned local engines, so wake-word transcription failed "OpenAI API key missing" while the working local whisper was never asked. Configured providers now win, local engines first: free, offline, no key.
- **Fixed: the same rule covers this Agent's own fallback.** When no daemon is reachable, the in-process speech-to-text route now also prefers the configured local engine instead of defaulting to a cloud provider that was never set up.
