- **Fixed: a turn hosted by the daemon looks like a turn.** The thinking indicator and its waiting state ran only for turns this process answered itself; a hosted turn now drives the same waiting state, streams its text as it is written, names the tool it is running, and counts the tokens it spent.
- **Fixed: wake tells the truth about the microphone.** A pinned capture device is a hint — capture moves to one that works and says so; a recorder backend that keeps failing is rotated out; listening is claimed only once frames arrive; and "no microphone on this machine" is reported as a different thing from "could not be checked".
- **Fixed: the Agent records why it died.** Every process-level fault writes a bounded record — message, stack, version, pid, open session — to `crashes.jsonl`, flushes a line to the activity log, and prints the reason to the terminal's own output channel, which the full-screen display cannot swallow.
- **Fixed: a hosted conversation is one you can come back to.** A hosted turn's transcript lands in this Agent's session store when the turn ends, however it ends; a surface that died mid-turn recovers what the daemon still holds on its next start; and settings reads resolve against the live daemon's own snapshot.
- **Fixed: a new turn is no longer finished by the previous turn's ending.** A fresh event stream per turn claimed no position and was handed the tail of the turn before it, which marked the new turn finished and discarded the answer being written. The stream now states the position it reached, and a turn-ending frame addressed to another turn is refused. Heartbeats keep arriving for every other conversation while one of them is answering.
- **Added: only one Agent per home.** A second Agent started against a home a live one holds stops at startup and names the process id holding it, instead of two copies writing over one another's sessions. A dead or recycled holder never blocks a start.
- **Added: the owner's terminal is untouchable on local turns too.** A command that drives an existing tmux session, window or pane this platform did not create is refused with the rule named; reading tmux state stays allowed and the platform's own sessions stay drivable.
